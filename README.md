# 2048 Clone in JavaScript

A simple web-based clone of the popular [2048 game](https://play2048.co/), built using HTML, CSS, and vanilla JavaScript.

![Game Screenshot](screenshot.png)

## 🎮 How to Play

Use your arrow keys to move the tiles. When two tiles with the same number touch, they merge into one! The goal is to create a tile with the number **2048**.

## 🚀 Features

- Responsive grid-based layout
- Smooth sliding tile animation
- Score tracking
- Game over and win conditions
- Restart functionality
- Mobile-friendly

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
